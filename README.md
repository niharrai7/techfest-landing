# Techfest 2026 Landing Page

A polished, no-3D-assets concept landing page for Techfest, IIT Bombay 2026.

## Concept
**An Aetherial Renaissance** — a dark editorial interface with acid-lime accents, subtle orbital geometry, grid texture, oversized typography and a high-energy science/technology feel.

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build
```bash
npm run build
```

## Notes
- React + Vite
- Lucide icons
- No 3D assets
- Responsive layout
- Official Techfest links used for CTAs
